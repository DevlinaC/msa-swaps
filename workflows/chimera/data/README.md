# Canonical Figure S9 data

- `domain_mapping.json`: exact CTD sequence mapping and construct length.
- `models.json`: all 50 AF2/AF3 model records, ranks, original paths/hashes, whole-model and CTD confidence, secondary-structure counts and CTD TM-score to the method's rank-one model.
- `summary.json`: method-level sample counts and descriptive summaries.

These analysis data are unchanged by the panel export. Each panel folder contains the relevant subset or a byte-identical copy for convenience. Use these canonical files when regenerating figures; see `../scripts/README.md`.
