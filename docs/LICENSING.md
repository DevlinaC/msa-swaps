# Licensing scope and attribution

The [MIT License](../LICENSE) applies to original project scripts and general-purpose code, together with their associated software documentation, except where a file carries different terms. This follows the code-versus-assets distinction used in the authors' [Expanding Protein Structure Prediction figure repository](https://github.com/DevlinaC/expanding-protein-structure-prediction-figures#license).

## Upstream software

Third-party implementations, adapted upstream code, dependencies and model weights retain their applicable licenses and notices. The project license does not relicense GREMLIN, ESM/MSA Transformer, MSA Pairformer, ColabFold, AlphaFold or any other upstream software. Preserve source attribution and applicable license text when redistributing code derived from those projects. Original source snapshots are preserved for provenance; their inclusion does not establish that they are original project code.

Model weights are obtained from upstream providers and are not redistributed here. Upstream repository links are listed in the main README.

## Figures, structures and scientific data

The project software license does not automatically license the manuscript, figure compositions, scientific datasets, protein coordinates or other non-software assets. Retain source-specific terms and attribution, including the recorded sources for PDB structures and CATH/ECOD annotations. The authors' data-release decisions and any separate asset licenses should be documented with the relevant files or archive.

AI-assisted development does not change these distinctions. The README's development disclosure describes the assistance used; it does not assert that every file was AI-generated or that AI use confers rights to third-party material.

## Pending asset release terms

A project-wide data/figure license has not yet been specified. The existing MIT code license must not be presented as permission covering every dataset, structure or figure. Record author-approved asset terms and archive-specific licenses before public release; see the [publication metadata checklist](PUBLICATION_METADATA.md#pending-release-metadata).
