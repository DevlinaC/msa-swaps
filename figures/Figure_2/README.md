# Figure 2 supplied query and donor plots

`supplied/` contains regenerated PNG/PDF exports from the original plotting scripts and the [packaged source tables](../../data/publication/Figures_2_3/README.md). The GREMLIN data retain the supplied historical fixed-100 selection. These exports are preserved for collaboration review and are not the revised main-panel contact analysis.

Run `python scripts/plot_main_figures.py --figure 2` from the repository root; outputs go to ignored `outputs/main_figures/`. The plotting-population checks and input provenance are described in the data guide. The supplied shading/metric labels are retained; ≥0.6 is not an established common threshold for the different metrics.
